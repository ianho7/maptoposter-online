# 海岸线拓扑分类 V2 实施 Checklist

> 来源计划：[plan-coastline-topology-v2.md](../plan-coastline-topology-v2.md)

## Checklist Objective

将海岸线海陆分类从“固定预算 + 左右偏移采样 + 全局失败”升级为“分辨率感知的拓扑保形简化 + 带来源的切分 + 区域边界邻接分类 + 区域级安全拒绝”。

目标结果：

- 里斯本西南侧大西洋能够生成水面。
- 纽约多块陆地不会被海面覆盖。
- 海口北侧海面继续存在。
- 南京玄武湖和岛屿语义不回归。
- PNG 与 SVG 使用相同的正确水体几何。
- 高密度或局部异常海岸线不再让整座城市的海面归零。

非目标：

- 不更换 OSM / Overpass 数据源。
- 不引入全球海陆边界数据。
- 不修改绿地、道路、POI 或 WASM 的绘制规则。
- 不承诺修复 OSM 本身严重缺失、错误方向或巨大断口。
- 不提交完整 10 MB 里斯本原始水体数据。

## Loop Spec

### Goal

- 外部可观察交付：真实应用导出的里斯本海报中，西南外海连续显示为水体，同时已知陆地不被覆盖。
- `complete` 证据：真实 PNG/SVG 验收通过，里斯本离线回归、纽约/海口/南京回归、类型检查与构建全部通过。
- `mitigated` 证据：离线回归已通过，但真实应用导出仍未验收；不得称为完成。
- `blocked` 证据：存在需要用户运行、外部数据或环境修复的明确门禁，并已保留最小复现、原始证据和下一步请求。

### Symptom and Acceptance Surface

- 用户症状：里斯本应用海报左下角本应为外海的区域呈现海报背景色。
- 确认根因：裁切后 `21,521` 条海岸线超过现有 `6,000` 条预算，生成器以 `processing-budget` 返回 0 个海面。
- 第二层边界：简化到预算内后，局部偏移采样仍产生歧义并触发全局退出。
- 最终验收面：真实应用的数据 Worker、缓存、V2 海面生成器、WASM 和 PNG/SVG 导出完整链路。

### Durable State

执行过程中直接更新本清单：

```yaml

phase: complete

acceptance_gap: none

```

每轮结束必须更新：当前阶段、状态、最近证据、未关闭的验收缺口和下一条任务 ID。原始输出保留在测试日志、诊断导出或明确路径中，不只写结论。

### Planner and Next-Action Rules

1. 没有稳定变红的里斯本测试，不进入生产实现。
2. 预处理不能把里斯本降到硬上限以内时，先检查容差和拓扑保持，不直接提高硬上限。
3. 拓扑边无法匹配时，先检查精度模型和环方向，不恢复偏移采样。
4. 支持验证通过但真实海报未验收时，状态保持 `mitigated` 或 `waiting`。
5. 新观察否定当前方案时，记录策略失败并回到最近通过的阶段门禁，不重复相同修改。
6. 任何陆地覆盖迹象立即触发 `risk_stop`，禁止以“海面显示了”为由继续扩大生成范围。

### Actor / Observer / Verifier

- Actor：修改 TypeScript 海岸线预处理、拓扑分类、缓存版本、诊断和测试夹具。
- Observer：记录测试退出码、诊断字段、线段数量、阶段耗时、生成区域数量、water-bin 数量和最终海报。
- Verifier：自动测试验证组件行为；离线真实数据重放验证数据链路；用户或人工真实导出验证最终接受面。
- 边界：实现者的总结不是完成证据；单元测试和离线重放不能代替真实应用导出。

### Failure Semantics and Retry Budget

| 失败类别 | 处理规则 | 预算 |
|---|---|---:|
| Transient | 同一命令保留原始输出后重试一次 | 1 |
| Strategy | 当前设计被证据否定，更新反思并切换策略，不原样重试 | 每个假设 1 次 |
| Environment | 停止无关代码修改，记录环境、命令、退出码和交接要求 | 连续 2 次后交接 |
| Policy | 停止并请求所需授权，不寻找绕过方式 | 0 |
| Unknown | 缩小输入或增加定点观测，未获得新证据前不得修复 | 1 次后必须收窄 |

### Exit Conditions

- `complete`：真实里斯本 PNG/SVG 通过，必需自动回归和构建通过，无陆地覆盖。
- `mitigated`：离线数据正确但真实运行链路尚未验收，明确保留接受门禁。
- `blocked`：下一步需要外部数据、用户操作或环境变化，已生成可执行交接。
- `budget_exhausted`：已用尽策略预算，保留尝试历史与最佳下一步。
- `risk_stop`：检测到陆地覆盖、拓扑破坏或不可接受的性能/内存风险。
